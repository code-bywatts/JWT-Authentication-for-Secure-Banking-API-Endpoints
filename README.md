# JWT Authentication for Secure Banking API Endpoints by VASU WATTS
Developed a secure Express.js banking API that utilizes JSON Web Tokens (JWT) for authentication and access control. The application includes endpoints for viewing account balance (/balance), depositing funds (/deposit), and withdrawing funds (/withdraw), each protected by JWT-based middleware to ensure authorized access. A dedicated /login route validates user credentials (hardcoded for demonstration) and issues a signed JWT token upon successful authentication. The project emphasizes secure API design principles, showcasing token-based authentication, middleware integration, and controlled access to sensitive banking operations within a Node.js environment.
